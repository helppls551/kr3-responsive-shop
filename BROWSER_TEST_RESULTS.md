# Результаты технической проверки (не Lighthouse)

Проверена сборка практической №13 на основе проекта №12.

- По статической проверке у всех пяти HTML-страниц есть ровно один `h1`, ровно один `main#main`, одна ссылка пропуска и один текущий пункт навигации.
- Проверены все локальные пути, `id`, подписи форм, наличие сообщений об ошибках, `alt` и синтаксис CSS/JavaScript.
- В Chromium отдельно от серверной навигации проверены пять размеров экрана: 360, 430, 768, 1024 и 1440 px; не обнаружено переполнения основной области страницы.
- Проверены фокус на skip-link, клавиша Enter, модальное окно, его закрытие по Escape, возврат фокуса, сообщения об ошибках форм и их демонстрационное отправление.
- Проверено отображение второго товара при якоре `#product-2`.

**Это не Lighthouse-аудит.** Отчёт Lighthouse требуется получить через DevTools в браузере и сохранить в папку `lighthouse/`.

Тесты в изолированном Chromium выполнялись с внедрением локальных HTML/CSS/JS в страницу, поскольку переход по локальным адресам блокировался окружением. Поэтому ручная проверка настоящей собранной страницы перед сдачей обязательна.
